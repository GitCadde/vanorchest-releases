# VanOrchest – Downloads

Hier liegen die Installer und Update-Dateien von **VanOrchest**, der Windows-App, die Claude Code und OpenAI Codex als ein Team steuert.

- **Installer:** unter [Releases](https://github.com/GitCadde/vanorchest-releases/releases) die neueste `VanOrchest_<version>_x64-setup.exe` herunterladen.
- **Updates:** Installierte Versionen aktualisieren sich automatisch aus diesem Repository.

Voraussetzungen: Windows 10/11 sowie eine eigene Installation von [Claude Code](https://code.claude.com/docs/en/setup) und/oder der [Codex CLI](https://learn.chatgpt.com/docs/developer-commands?surface=cli) mit eigenem Login.

Der Quellcode ist nicht Teil dieses Repositories.
